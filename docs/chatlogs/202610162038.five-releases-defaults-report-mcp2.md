## Session summary
This session started from a Loom Plan 26 request from demeter-loom-1: OpenRouter's default model, `openai/gpt-4o`, is being retired. It ended with four PyPI releases (0.5.1, 0.5.2, 0.5.3, 0.6.0), a live check of three new defaults, a secret-scan gate, a landing-page update, and the MCP server ported to the mcp 2.x SDK.

## Decisions made
1. **OpenRouter's default becomes `openai/gpt-6-sol`** (Bart's ruling). Bart also ruled to fix all four other retired or retiring defaults: deepseek → `deepseek-flash`, groq and together → `openai/gpt-oss-120b`, gemini → `gemini-3.5-flash-lite`. xai, mistral and ollama are unchanged.
2. **A single-vendor review is reported as what it is.** The report no longer calls a same-vendor review "independent". The cross_review warning names the vendor that actually ran the review. LaTeX inside `\( \)` and `\[ \]` is turned into plain text.
3. **Saved runs are exposed as MCP resources**: `rapier://runs`, `rapier://runs/{id}` and `rapier://runs/{id}/record`. The `list_runs` and `get_run` tools remain.
4. **mcp<2 in 0.5.3, then a port to 2.x in 0.6.0.** mcp 2.3.0 removed FastMCP, so fresh installs of 0.5.x broke. The cap fixed that right away. The port then moved the server to `MCPServer` and set the requirement to `mcp>=2.3,<3`.
5. **Deprecation warning filtered by message.** mcp 2.x raises its logging deprecation warning from inside the SDK, so a filter keyed on the module doesn't match it.
